## 🧠 Projects


- **Sales & Customer Behaviour Dashboard** – Built an interactive Streamlit dashboard for a food‑tech start‑up. Implemented segmentation, retention cohorts and churn analysis modules using pandas, scikit‑learn and MongoDB, and deployed it on a scalable platform.  
- **2D Echocardiogram Video Phase Detection** – Developed a semi‑supervised deep learning pipeline (Autoencoder + Bi‑LSTM + Attention) to detect cardiac phases. Integrated U‑Net segmentation and achieved **99.3% phase** and **97.9% volume accuracy**.  
- **NFT Explorer & Price Predictor** – Trained regression and LSTM models to predict NFT prices with 85% accuracy; built interactive dashboards with Streamlit and Power BI; managed an MLOps pipeline using DVC, Docker and AWS.  
- **OpenMRS Test Automation** – Automated hospital workflows (login, patient registration, discharge) using Java, Selenium and TestNG, reducing manual testing time by **60%**.  
- **AstroGo – AI Astrology Platform** – Fine‑tuned GPT‑4o on a curated astrology dataset for Kundali generation. Built a FastAPI backend with a React frontend and deployed on Vercel for low‑latency consultations.
